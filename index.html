    How the hybrid routing works

    1. Short note → on-device first. Firebase AI Logic (firebase/ai) creates a model with InferenceMode.PREFER_ON_DEVICE: Gemini Nano in Chrome handles it locally — fast, private, works with no signal in the garden. If Nano isn't available, the SDK falls back to the cloud automatically.
    2. Long log → cloud. Past 600 characters / 90 words, the app escalates to a cloud Gemini model (PREFER_IN_CLOUD) for a fuller structured summary (date, plants, tasks, issues).
    3. The badge never lies. Each result's badge comes from response.inferenceSource — the SDK's own report of whether the answer was generated on-device or in the cloud.
